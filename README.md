# Проект тестирования интернет-магазина (qa-engineer-project-84)

## Описание проекта
Тестирование учебного интернет-магазина в рамках курса «Инженер по тестированию» на Хекслете. Проект включает в себя полный цикл тестирования: от анализа требований до составления отчетов о регрессе.

## Содержание репозитория
- `about.yml` — информация об авторе проекта.
- `requirements.yml` — анализ требований (функциональные, нефункциональные, неявные).
- `test-cases.yml` — детальные тест-кейсы для проверки магазина.
- `testing-report.yml` — отчет о первичном тестировании (статусы тест-кейсов).
- `bugreports.yml` — баг-репорты на найденные дефекты.
- `regress-report.yml` — отчет о регрессионном тестировании новой версии.
